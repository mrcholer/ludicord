# Ludicord examples

These examples use the current stable Ludicord release and are compiled in
GitHub Actions.

## Full-stack starter

[`full-stack-starter`](full-stack-starter) is a complete Discord Activity with:

- a persistent Activity shell and typed embed navigation;
- authenticated Discord user, guild, channel, and participant data;
- automatic authentication, minimized, and loading states;
- an authenticated HTTP API route;
- a realtime WebSocket audience route;
- responsive safe-area-aware CSS; and
- production build and start commands.

For smaller focused snippets, read the
[community tutorial series](https://github.com/mrcholer/ludicord/discussions/3).
