# Ludicord workspace rule

For every Ludicord Activity task, read `AGENTS.md` and the canonical `skills/ludicord/SKILL.md`. The `.agents/skills/ludicord/SKILL.md` file is only a discovery adapter.

Use the installed package declarations and generated route declarations as the API authority. Preserve framework conventions and server/client security boundaries. Never use `ludicord/internal` in application code. Run the applicable route, hook, type, and production-build checks before reporting success.
