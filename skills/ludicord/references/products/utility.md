# Utility Product Profile

Activate for focused tools whose value is completing a specific task quickly:
calculators, converters, generators, helpers, builders, small workflow tools,
forms, inspectors, or similar utilities.

## Rules

- Minimize navigation and ceremony.
- Put the primary input/action/result path first.
- Validate invalid input close to where it occurs.
- Persist only settings/history the user actually benefits from.
- Do not add account systems, social features, dashboards, or realtime unless
  required.
- Do not gamify the task by default.
- Professional UI means clear state, keyboard/touch usability, responsive
  layout, accessibility, and predictable errors—not more panels.
