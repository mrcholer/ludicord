# Contributing

This repository accepts public documentation corrections, usage-example improvements, bug reports and feature requests. It is not the framework source repository.

Before submitting:

1. Check whether the guide covers a published version or the upcoming 2.2.4 preview.
2. Keep changes limited to Markdown documentation and the existing issue-template configuration.
3. Verify relative links and runnable usage snippets.
4. Remove credentials, private paths, user data and private implementation details.
5. Describe the correction and the version it applies to.

Do not add framework source, compiled output, source maps, dependency directories or source-repository history. A source-code pull request to the private implementation cannot be made from this repository.
