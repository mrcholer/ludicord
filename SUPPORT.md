# Support

Read [troubleshooting](docs/troubleshooting.md), then search the [issue tracker](https://github.com/mrcholer/ludicord/issues) before opening a new issue.

Include:

- Installed Ludicord and generator versions, Node version and package manager.
- Development or production mode; Discord desktop/mobile/web or outside-Discord browser.
- Minimal reproduction steps and expected versus actual behavior.
- Sanitized error text and relevant configuration with all secret values removed.

Run `ludicord info`, `ludicord routes`, `ludicord lint`, and a production
`ludicord build` locally. Review their output before sharing; redact local
paths, user/guild/channel IDs, and sensitive data.

Never attach `.env` files, credentials, cookies, access tokens, private source archives or customer data. Use a small example you have permission to share.

For vulnerabilities, use [security reporting](SECURITY.md), not a public bug report. There is no guaranteed support response time.

For usage questions, open a
[Q&A discussion](https://github.com/mrcholer/ludicord/discussions/categories/q-a).
For community chat or moderator help, join the
[Ludicord Discord server](https://discord.gg/FzvXfvyPVe).
