# Latest Ludicord release

The latest synchronized public release is **Ludicord 3.0.1**, published for both `ludicord` and `create-ludicord-app`.

## Install

Create a new Activity:

```bash
npx create-ludicord-app@latest my-activity
```

Update an existing Activity:

```bash
npm install ludicord@3.0.1
```

Use the equivalent command for the project's existing package manager and commit the updated lockfile.

## Release summary

This patch release improves clean-clone compatibility checks and keeps generated projects focused on the commands most applications need.
