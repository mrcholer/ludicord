# Latest Ludicord release

The latest synchronized public release is **Ludicord 4.1.2**, published for both `ludicord` and `create-ludicord-app`.

## Install

Create a new Activity:

```bash
npx create-ludicord-app@latest my-activity
```

Update an existing Activity:

```bash
npm install ludicord@4.1.2
```

Use the equivalent command for the project's existing package manager and commit the updated lockfile.

## Release summary

Ludicord 4.1.2 makes restricted host configuration work automatically with your application's Discord Activity proxy domain.
