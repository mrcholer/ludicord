# Latest Ludicord release

The latest synchronized public release is **Ludicord 3.1.0**, published for both `ludicord` and `create-ludicord-app`.

## Install

Create a new Activity:

```bash
npx create-ludicord-app@latest my-activity
```

Update an existing Activity:

```bash
npm install ludicord@3.1.0
```

Use the equivalent command for the project's existing package manager and commit the updated lockfile.

## Release summary

Ludicord 3.1 strengthens production Discord Activities around authentication, Activity-instance isolation, realtime reliability, and multi-process deployment.
