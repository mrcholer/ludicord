# Repository scope

This is the public documentation and release-information repository for Ludicord.

## Included

- User-facing guides, supported configuration and public API descriptions.
- Small usage examples written for application developers.
- Public release dates, preview notes, limitations and upgrade guidance.
- Bug reports, feature requests and documentation contributions.

## Excluded

- Framework implementation and original source history.
- Private applications, internal test fixtures and unpublished customer data.
- Environment files, credentials, access tokens and session material.
- Compiled bundles, source maps, npm tarballs and dependency directories.

Do not upload a source-repository archive or use an automatic mirror into this repository. Maintainers review an explicit documentation-only file list before each update. GitHub's automatically generated release archives contain only this documentation snapshot, not framework source or package binaries.

## Package licensing

This repository's visibility does not change the license of any npm release. Check the license metadata and notices of the exact package version you install. A documentation-only GitHub repository does not make code already distributed in npm packages confidential.

## Documentation versions

The main branch currently documents the upcoming 2.2.4 release. Published version numbers and dates are tracked separately in [release history](CHANGELOG.md). Preview notes are not evidence of an npm publication.
